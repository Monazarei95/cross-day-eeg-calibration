# Published experiment outputs

These files preserve scored BCI IV 2a and OpenBMI summaries with frozen trial predictions. The hand-only directories contain new binary predictions, provenance references, participant scores, and signal diagnostics. The inventory lists SHA-256 digests of the bundled scientific outputs.

Development revision identifiers in the experiment log identify the original local research records. The first public commit is a release snapshot; the second adds the exploratory hand-only analysis.
