How the experiment worked

Imagine a movement

Nine people imagined moving their left hand, right hand, both feet or tongue. A cap recorded electrical activity from the scalp, called EEG.

Learn on the first day

A model learned patterns from eight other people’s unlabeled recordings. For the ninth person, a separate eye-movement recording calibrated the signal, and ten labeled examples per movement taught the model the four names.

Return on another day

The same person returned and the model used scalp EEG alone. Each person took a turn as the test participant. Predictions for all 2,592 trials were fixed before scoring.

What if we compare only left and right hands?

We trained new two-choice classifiers and scored only the 144 hand trials from each person’s second day. Guessing would average 50%. This analysis was planned after the four-choice results were known, so it is exploratory.

The best average stayed below 80%. The classical model remained stronger. The hard eye correction retained 11.26% of measured 8–30 Hz signal energy. That energy includes both brain activity and artifacts, so we cannot tell how much neural information it removed. Read the full hand-only analysis.

What can we conclude?

Eight of nine people improved with eye calibration in the main comparison. The result met the target set before scoring. With nine people, the size of the benefit is still uncertain.

Scalp-only calibration reached 40.08% with the same model. The extra 1.21 points from eye electrodes had a 95% interval from −0.24 to +2.66. The best average score across all conditions was 47.26%, using the classical model with scalp-only calibration.

What happened to the original training idea?

An earlier experiment used eye signals to choose which recordings the model compared during training. It fell short of its target. The gain above came from using the eye recording to correct the input signal.

Independent follow-up · OpenBMI

Will it work for another group?

The follow-up tests scalp-only calibration in 54 people imagining left- or right-hand movements. It asks whether a returning user can benefit without wearing eye electrodes.

Across 54 people, scalp-only calibration changed next-day balanced accuracy by +0.89 percentage points (95% confidence interval -0.33 to +2.10). 28 people improved.
